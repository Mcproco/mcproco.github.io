Github Repository ->

Well, you're probably going to be a bit underwhelmed by the fact that there isn't any tangible work here. Its all accessible through the github, as linked above.

The community aspect comes from the fact that I've donated all of my free hours to the public, for anyone to modify, enhance, and run my project. You reserve the right to use the project as defined in the GPL 3.0v, which is what my project is licensed under.

I encourage you to give it a test spin, open a PR, and use it as a platform for any of your own projects. Don't worry if you don't know how to program, if you know any basic level of algebra I'm confident you'll be a fast learner. All it takes is a bit of patience. Actually a lot of patience but you'll get through it.

(PS, learning becomes 1000x more difficult when you offload cognative ability and critical thinking to generative A.I. So try your best not to default to it, trust me)
